# StocksX

StocksX is a Next.js stock research workspace with a device-local watchlist, market exploration, historical charts, technical analysis, a hypothetical portfolio calculator, backtesting, and statistical forecasts.

## Run locally

```bash
npm ci
npm run dev -- --hostname 0.0.0.0 --port 3000
```

Then open `http://localhost:3000`. The main page is the watchlist. Use **Command+K** (or **Ctrl+K**) to search for a stock, app page, settings section, or research section.

A fresh session does not preselect a chart ticker. Chart Analysis, Predictions, and Backtesting ask you to choose a symbol; selecting one in the stock picker returns directly to the requested research area, and each selected-stock workspace provides an in-place way to change symbols. The startup readout begins at `STOCK 52%` and moves to `100%` when the real initial data state settles. On phone widths, chart panels stack and wide data tables scroll rather than clip.

## Market data

The server-side API routes use `yahoo-finance2` for search, quotes, historical prices, and company-profile fields. Watchlist and benchmark quotes are batched, duplicate provider calls are shared, and requests have bounded deadlines. Yahoo Finance data can be delayed, unavailable, or rate-limited. The app does not replace missing prices with demo values: it shows loading, stale-data, or unavailable states. Short-lived caches contain only real provider responses.

## Local profile and storage

On first use, enter a display name to create a local profile. This is not a real account or authentication system. The name, watchlist, and display preferences are stored in this browser and are not synced as account data to another device. The display name is never sent. Symbols and relevant chart/forecast parameters are sent in live-data requests so the server can retrieve Yahoo Finance data; the app does not persist a user watchlist or profile on the server. Clearing the local profile returns to the name prompt.

## Forecasts and trading

Forecasts are generated by the existing deterministic linear-regression and EMA ensemble using provider historical closes. Scores and model-signal labels are statistical heuristics, not calibrated probabilities, proof of performance, investment advice, or instructions to trade. The portfolio calculator uses user-entered hypothetical quantities/cost basis and actual provider quotes. The app does not place orders or connect to a brokerage. Historical comparisons may omit fees, taxes, spreads, slippage, survivorship bias, and corporate-action edge cases.

## Deploy to Vercel

This is a Next.js App Router application with server-side API routes, not a static export. The root `vercel.json` selects Vercel’s Next.js framework, runs `npm run build`, and overrides the output directory to `.next` so deployment does not look for a static `public` build folder. In Vercel, set the Root Directory to the folder containing this `package.json` and `vercel.json`; if the deployment still reports `public`, select the Next.js Framework Preset and remove any conflicting project-level Output Directory override.
